# DECISIONS

- `docs/` lama berisi HTML hasil crawl bercampur dengan brief; HTML dipindah ke `legacy/docs-pages/`, `docs/` hanya dokumen proyek.
- `.gitattributes` `eol=lf` dan `core.autocrlf=false` agar tidak ada noise CRLF di Windows.
- Vercel Hobby melarang penggunaan komersial: produksi berpenghasilan perlu paket Pro.
- Foto/ikon pihak ketiga di `legacy/shared/` hanya dipakai sesuai izin merek masing-masing.
- Crawl lama tetap disimpan di `legacy/` sebagai acuan sesuai CLAUDE.md; boleh dihapus setelah Tahap 1 selesai atas keputusan pemilik.
- **Palet/kontras:** swatch resmi `#262626/#676B6C/#AABBC5` dipakai apa adanya. `#676B6C` (3.2:1 di `#1B1B1B`) tidak lolos AA untuk teks, jadi hanya dipakai untuk garis. Teks redup memakai turunan lebih terang: `--v2-t-4 #A0A9AD`, `--v2-t-5 #98A1A5` (≥4.5:1 di semua permukaan bg). Teks putih alfa <0.5 di halaman docs/legal hasil crawl masih di bawah AA; perlu audit per halaman.
- **CSS:** halaman memakai CSS Tailwind terkompilasi hasil crawl (brand lain dibuang oleh `legacy/tools/build-css.py`), bukan Tailwind live. Kelas baru yang tidak ada di CSS itu ditaruh di `app-utils.css`. Migrasi ke Tailwind sungguhan ditunda **[di luar brief]**.
- **Halaman statis** (landing, about, docs, legal, social) dihasilkan oleh `legacy/tools/html-to-tsx.py` dari `legacy/`; copy ditulis ulang lewat tabel `PHRASES` di skrip itu. Setelah `legacy/` dihapus, file `page.tsx` hasil menjadi sumber kebenaran dan skrip tidak dipakai lagi.
- **Layar `/application/*` dan `/auth/signin`:** HTML crawl hanya berisi skeleton loading (UI aslinya di chunk JS), jadi layar ditulis ulang sebagai komponen React memakai kelas CSS yang sama dan data fixture. Fidelity visual terhadap aplikasi lama belum 1:1.
- **Fixture** dihasilkan `packages/api-client/scripts/make-fixtures.mjs` dari seed lama, hanya entri Solana (alamat `0x…` dibuang). Daftar smart wallet diisi alamat dari sampel trade dengan statistik sintetis (ditandai `fixture: true`).
- Logo belum ada: gambar logo lama dihapus dari halaman statis; teks wordmark "Corvid" jadi placeholder (`data-placeholder="logo"`). OG image `/og-image.png` adalah placeholder teks.

- 2026-11-04 Palet diperbarui atas permintaan pemilik: background halaman `#262626`; permukaan hitam (header, panel, input, cookie) `#000000`; teks putih sekunder `#686B6C`; aksen (ex-oranye) `#FFFFFF` ("Casper FFFFF" dibaca sebagai `#FFFFFF`, ubah di `PAL` build-css.py bila yang dimaksud `#AABBC5`). Kontras `#686B6C` di atas `#262626` sekitar 2.8:1 (di bawah AA), di atas `#000000` sekitar 3.7:1. Keputusan pemilik; tinjau ulang bila perlu AA.

- 2026-11-04 Palet BARU menggantikan semua palet sebelumnya (pemilik): Cloud Mist `#D7E1EC` (section terang), Signal Blue `#0030CF` (ex-oranye: tombol, garis, glow), Pure White `#FFFFFF` (teks utama), Deep Charcoal `#13171B` (latar & permukaan; turunan lebih terang `#171C21`..`#29323A` untuk lapisan). - 2026-11-04 Layar aplikasi (`/application/*`, `/auth/signin`) dibuat dari snapshot DOM referensi (`legacy/snap`, view chain Solana) lewat `legacy/tools/snap-to-tsx.py`: tampilan identik, tetapi statis (belum interaktif) sampai integrasi Tahap 2/3. Data contoh berasal dari mock referensi, alamat `0x…` dipetakan ke string base58 dummy, DEX "uniswap" menjadi "raydium".

- 2026-11-04 [KEPUTUSAN PEMILIK] Frontend = build asli referensi (Next.js terkompilasi) yang di-rebrand + diganti palet, BUKAN tulis ulang manual: kesamaan efek (Lenis smooth scroll, framer-motion, efek kursor/hover, shader WebGL, three.js, dropdown navbar) harus persis. `legacy/tools/rebrand-build.py` menghasilkan `apps/web/public/c/**` (HTML + `_next/static` ter-patch); `apps/web` (Next.js 15) menyajikannya lewat `rewrites` fallback dan menyediakan API (`src/app/api/[...path]`, data contoh di `src/server`). Hasil build DI-COMMIT supaya `legacy/` boleh dihapus. Patch: nama brand, palet (CSS + HTML + flight RSC + JS + vec3 shader), Supabase lama dihapus, logo gambar lama disembunyikan (wordmark teks), panjang baris flight `T<hex>,` dihitung ulang. Perubahan warna harus konsisten di HTML/flight/JS agar hydration React tidak mismatch (#418).
- 2026-11-04 [DITUNDA atas instruksi pemilik: "cuma ganti color palette"] Pembersihan EVM (chain Ethereum/Base di UI, copy "0x", "Uniswap", `$APE` di data mock) tidak dilakukan pada bundel ini; dikerjakan saat integrasi backend (Tahap 2). Gambar raster `how-*.jpg/mp4` masih berwarna lama (butuh aset baru dari desainer).

- 2026-11-04 [KEPUTUSAN PEMILIK] Halaman harus identik dengan HTML referensi tetapi ditulis dalam TypeScript. Dikerjakan bertahap: komponen bersama diport dari kode referensi (yang terbaca) memakai library yang sama (framer-motion 14, @phosphor-icons/react): Navbar + NavDropdown (hover 140 ms, spring highlight), Footer (sudut bracket hover), CookieBanner (1,6 dtk, `corvid_cookies`), BootLoader (0-100%, sekali per sesi, `corvid:loaded`), LegalLayout (indeks aktif + bilah progres), DocsShell/DocsNav/TableOfContents. Isi dokumen (about, privacy, terms, 17 halaman docs) = JSX statis hasil `legacy/tools/gen-legal-pages.py` dan `gen-docs-pages.py`. Rute yang belum dikonversi (landing, social, layar aplikasi, signin) tetap disajikan dari bundel asli (`public/c`) lewat rewrites fallback; rute TypeScript otomatis menang atas fallback.

Sumber generator = `legacy/rebranded/**` (HTML hasil `rebrand-build.py`), generator: `gen-legal-pages.py`, `gen-docs-pages.py`, `gen-landing.py`, `gen-social.py`, `gen-app.py` (layar aplikasi dari `legacy/snap`). - 2026-11-04 [JAWABAN HEAD DEV] Wallet: "pakai semua yang bisa ke Solana". - 2026-11-05 **[KEPUTUSAN PEMILIK] Status `legacy/`:** hasil REA dari apevisor (brand milik pemilik), dipertahankan hanya sebagai acuan tampilan dan wawasan backend (kontrak API, skema DB, bentuk response). Seed `legacy/be/data` yang berisi alamat 0x/ETH dibersihkan sebelum dipakai; URL/anon key Supabase lama tidak boleh dipakai.

- 2026-11-05 [TERBUKA] **Arsitektur wallet.** (a) Koneksi wallet non-kustodian (Wallet Standard/`@solana/wallet-adapter`, login tanda tangan/SIWS + Supabase Auth) dipasang di Tahap 2 bersama auth, bukan Tahap 1. MetaMask hanya lewat akun Solana; dukungan devnet dan deteksi Wallet Standard dites langsung; cadangan Phantom/Solflare dengan wallet dev kosong. (b) Wallet kustodian dipakai agar agent bisa trading otomatis saat user offline dan agar user email tanpa wallet bisa mulai. Dibangun di Tahap 3 dengan kunci dummy/devnet dan `TRADE_MODE=dry`; KMS (AWS/GCP KMS atau master key env) belum diputuskan. (c) Alternatif tanpa menyimpan kunci user (izin terbatas/session key ke agent) belum ada di brief; perlu keputusan pemilik/head dev sebelum mainnet. Enkripsi envelope wajib, kunci tidak pernah di log/repo, `live` hanya atas izin eksplisit.

- 2026-11-05 **[DEFAULT 2a]** Daftar tabel final mengikuti `docs/db-analysis.md`: Solana-only (kolom chain dibuang), `transfer_fee_bps` menggantikan buy/sell tax, `token_security_metrics`, `token_candles`, tabel pengguna dengan RLS, kunci kustodian di `user_wallet_secrets` tanpa policy klien, seed `0x` lama tidak dipakai, retensi ingest target total sekitar 400 MB. Verifikasi REA pada chunk halaman dijadwalkan sebelum migrasi dikunci; pemilik dapat mengubah default ini.

- 2026-11-05 **[API]** Fastify + zod + OpenAPI di `apps/api`; bentuk response sama dengan mock lama (path `/api/tokens/trades?mint=`, `/api/tokens/:mint/security`). `buyTax`/`sellTax` tetap ada di response sebagai turunan `transferFeeBps` (persen) agar UI lama terbaca; ditambah `transferFeeBps`. Daftar `risks` diturunkan dari kolom (top10, dev, authority, rugged), tidak disimpan. Mint tidak dikenal = 404 `token_not_found`, bukan data sintetis seperti mock lama. `chain` hanya menerima `solana` (400 untuk nilai lain), mint harus base58 (400 untuk `0x`). Seed di `apps/api/seed` menyaring mint non-Solana dan DEX EVM (dex `uniswap` jadi null). Postgres embedded wajib `--encoding=UTF8` (default Windows WIN1252 menolak nama token Jepang).

- 2026-11-05 **[Frontend ke API]** `apps/web/src/lib/api.ts` (`apiGet`, `useApi`): mode fixture memanggil `/api/*` lokal Next; `NEXT_PUBLIC_USE_FIXTURES=false` + `NEXT_PUBLIC_API_URL` memanggil Fastify. Latest/Gainers/Volume, Memescope, dan status bar SOL sudah memakainya. `/api/prices/sol` memakai CoinGecko (tanpa key), cache 30 dtk, nilai lama dipakai sampai 10 mnt bila sumber gagal, selebihnya 503. Port 3100 di mesin pemilik dipakai proses lain; uji lokal memakai port 3217.

- 2026-11-05 **[API search/chart/live-batch]** `GET /api/search?q=` (token: simbol awalan, nama mengandung, mint; agent terbit; wallet curated; `notice` bila mint valid tapi belum terindeks, LIKE di-escape), `POST /api/tokens/live-batch` (maks 50 mint, `{data:{mint:{...}}}` seperti klien lama), `GET /api/tokens/chart?mint=&type=1m|5m|15m|1h|4h|1d` **[di luar brief]**: bentuk `{mint,type,candles:[{time(detik),open,high,low,close,volume}]}` didefinisikan sendiri karena konsumen chart tidak ada di crawl. Candle belum diisi apa pun sampai worker ingest ada (tidak ada data sintetis); kosong = `candles: []`.

- 2026-11-05 **[PENTING: CSS]** `apps/web` tidak punya build Tailwind. Kelas utilitas hanya bekerja bila sudah ada di CSS hasil kompilasi referensi (`public/c/_next/static/css/*.css`) atau di `src/app/corvid.css`. Untuk komponen baru: pakai kelas yang sudah ada (cek dengan `grep -F ".nama-kelas"` pada CSS itu) atau gaya inline/`corvid.css`; nilai arbitrary baru (mis. `grid-cols-[56px_1fr]`, `max-w-[1200px]`) tidak akan terbentuk. Halaman detail token memakai `max-w-[1400px]` dan `gridTemplateColumns` inline.
- 2026-11-05 **[Detail token]** `/application/tokens/[mint]`: mint non-base58 (mis. `0x…`) = 404 Next; mint valid tapi belum terindeks = pesan "Token not found". Chart SVG buatan sendiri (tanpa dependensi); candle kosong menampilkan "No chart data". Catatan seed: sampel rugcheck dan trades dari crawl lama dipasang ke token sampel (Tripod) sehingga isinya tidak cocok dengan tokennya; data nyata menunggu worker ingest.

- 2026-11-05 **[Search di command palette]** Mode API memakai `GET /api/search` (debounce 220 ms, request lama dibatalkan, `notice` tampil sebagai banner, gagal = pesan "Search is unavailable"); mode fixture tetap memakai indeks lokal. Hasil wallet dari API ditambahkan di samping baris alamat yang diketik; agent dari API ditandai status `active` karena API belum mengirim status. Baris "Open token by address" untuk mint valid tetap ada walau belum terindeks (halaman detail akan menampilkan "Token not found").

- 2026-11-05 **[Worker ingest]** `apps/worker`: sumber tanpa key, GeckoTerminal (trending_pools, new_pools, OHLCV, trades) + DexScreener (`/tokens/v1/solana/{mints}`, batch 30, pasangan likuiditas tertinggi). Semua respons divalidasi zod; fixture tes adalah sampel respons asli. Token dari pool GeckoTerminal tetap tampil walau DexScreener belum punya (nama/harga dari pool, gambar kosong). Upsert tidak menimpa kolom terisi dengan null; kolom keamanan (risk, holders, top10, dev) **tidak diisi** sampai ada Helius, tidak dikarang. `solAmount` di trades hanya diisi bila token kuotasi pool adalah wSOL (banyak pool berkuotasi token lain). Batas laju GeckoTerminal ternyata ketat: 2,2 dtk/request memicu 429, default sekarang 6,5 dtk (~9/mnt), papan tiap 2 mnt, candle dan trades tiap 10 mnt untuk 10 token teratas; `WORKER_GT_INTERVAL_MS` dapat diubah. Retensi per `docs/db-analysis.md` (trades 48 jam, candle 15m 7 hari, dst.). Memescope (tahap pump.fun) belum punya sumber; tabel tetap berisi seed sampai ada sumber.
